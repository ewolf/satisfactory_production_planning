PARTS:

thing selection UI:
  The thing can be any data structure with a name
     - lists added things with an [x] that is clicked to remove them.
     - at the bottom is a select and added things are filtered out of its options
     - a button to add the selected thing.

item rate selection UI:
  Like the thing selection ui, but with a numeric input for rate after the select.

item percentages UI: corresponds to a given hash of item -> destination -> percentage.
 one item may have multiple destinations.
 - Shows existing values of the hash
    ~ item name (not editable)
    ~ select showing destinations, used to add a destination
    ~ list of
      > destination (with control to remove it)
      > number input for percentage

* PowerConfiguration:
   - a select contains power generating buildings labelled 'Generator Type'
   - a select containing fuels allowed by the selected power generating building labeled 'Fuel'
   - numeric input for clock speed, limited to valid values
   - numeric input for number of buildings with this config
   - control to remove this configuration

* RecipeConfiguration:
   - select of StandardRecipeList plus UnlockedRecipesList (sorted by name)
   - name of building that produces the selected recipe
   - numeric input for clock speed, limited to valid values
   - numeric input for number of sommersloops, limited to valid values
   - numeric input for number of buildings with this config
   - control to remove this configuration

  * ExtractionConfiguration:
     - select of ExtractionBuildingList labelled 'Building Type'
     - select of resource items from building's resourceOutputHash
     - select for purity: impure, normal, pure
     - numeric input for clock speed, limited to valid values
     - numeric input for number of buildings with this config
     - control to remove this configuration

* ConfigList: for power or recipe configuration
   - displays list of configurations
   - has a control to add a new configuration


COMPOSITION

* the title

* saving controls in a row
  - load json file
  - save as json
  - empty cache

* global settings:
  - belt level: select, default is level one. the options show belt level and rate.
  - pipe level: select, default is level one. the options show pipe level and rate.
  - unlocked alt recipes:
      ~ thing selection UI, populated by the AlternateRecipeList. selected items are added to UnlockedRecipesList.

* global report:
  - show total power used /  total power produced (across all power grids and production lines)
  - show 'goals' in an indented list
     collate the product goals of all the product lines. 
     present these like  'item' 12/34 per minute.
        ~ if both numbers are the same, just show one number
	~ if the producing is equal or greater to the goal the numbers are green
	~ if producing is zero, put numbers in red
	~ otherwise use yellow

* a row with Production Lines and Power Grids side by side

* Production Lines:
  - column of divs with a lighter background and borders. These are collapsable and are
    by default collapsed if there is more than one.

     ~ collapsed shows name of production line, and then list its target item names.

     ~ uncollapsed shows the full production line UI (see below)
  - control to add a new line

* Production Line UI:
   - editable name
   - control to delete this line
   - Enabled toggle: checkbox to enable/disable the line. Updates isEnabled
   - Status indicator: displays "ON" if isOn is true, "OFF" if false
   - Power Connection:
      ~ select dropdown, populated by PowerGridList. Includes 'No Connection' as default option. Updates PowerGridConnection
   - Target Production:
      ~ item rate selection UI, populated from ProductionItemList.
        Updates ProductionGoalHash like 'iron plate' => 10 for 10 iron plates per minute.
   - Production Configurations
      ~ ConfigList for RecipeConfiguration, populated from ProductionConfigList
   - Extraction Configurations
      ~ ConfigList for ExtractionConfiguration, populated from ExtractionConfigList
   - fuel export UI
      ~ item percentage UI, displays and updates FuelsExported.
   - item export UI
      ~ item percentage UI, displays and updates ItemsExported.

* Production Configuration UI: This groups buildings of one type and configuration together. The player sets these
   to describe the current state of buildings for the line.
   It is a ConfigList for RecipeConfiguration populated by ProductionConfigList of the ProductionLine.


* Power Grids:
  - column of divs with a lighter background and borders. These are collapsable and are
    by default collapsed if there is more than one.

     ~ collapsed shows name of grid line and power used / power produced

     ~ uncollapsed shows the full power grid UI
        > list of PowerConfigurations mapped to PowerConfigList
	> control to add a new configuration
  - control to add a new grid
